# Install Gazebo
When you want to install or have already installed PX4 you need to launch the following script : 
```bash
./install_px4_gz_ros2_for_ubuntu.sh
```
It will do theses operation : 
- Install Gazebo
- Let you chose the PX4 version you need if it isn't installed
- Copy the model and world files in the folder PX4-Autopilot-PATCH
